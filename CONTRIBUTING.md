# Contributing

DevMemoir is currently an owner-led project. Issues and pull requests may not be accepted, and opening one does not imply a planned release or support commitment.

Please run the relevant checks before proposing a change, including `pnpm typecheck`, `pnpm lint`, `pnpm test`, and `pnpm audit:public` when applicable. Keep changes focused and document behavior that affects the architecture or privacy boundary.

Do not submit real secrets, private repository content, raw webhook payloads, or personal data. Security reports must not use public issues; follow [`SECURITY.md`](./SECURITY.md) instead.
